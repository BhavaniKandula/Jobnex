# Jobnex – Job Portal Web Application

Jobnex is a job portal web application built using Python, HTML, CSS, and JavaScript.

## Features
- Simple and user-friendly interface
- Python-based backend
- Frontend built with HTML, CSS, and JavaScript
- Database connectivity and testing

## Technologies Used
1.Python
2. HTML5
3.CSS3
4.JavaScript
5.SQL

## Project Structure
- `Frontend/` – HTML, CSS, and JavaScript files
- `backend/` – Python backend and testing files

## Getting Started
1. Clone the repository:
   `git clone https://github.com/BhavaniKandula/Jobnex.git`
2. Open the project folder in your IDE.
3. Follow the backend setup instructions to run the application.
